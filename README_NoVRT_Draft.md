# Radio Online Pro — no-VRT draft

VRT catalog and VRT playback are removed in this draft. Saved VRT stations/favorites are cleared on migration. Player, AirPlay, sleep timer and AdMob consent/test integration remain. Commercial ads are disabled and cannot be enabled for an empty catalog.

This is NOT a release candidate: the catalog is currently empty pending documented rights for replacement stations. Do not submit an empty radio player to App Review. Existing TestFlight build 5 is not changed by this draft. Xcode tests are updated for VRT removal but have not been run for this draft; the prior build 5 validation does not validate it.

Research: SomaFM does not authorize new third-party apps (https://somafm.com/contact/tos.html). laut.fm terms restrict commercial use (https://laut.fm/pages/terms_and_conditions). MUGEN developer terms require a commercial license and contain differing CC BY/CC BY-NC wording (https://mugenradio.com/developers.html). None has been added, contracted or paid.
