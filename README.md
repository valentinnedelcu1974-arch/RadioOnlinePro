# Radio 43 — free, no app-added ads

Native iPhone radio app: 21 official VRT streams plus MDK Space Radio. Favorites, local search, background/lock-screen playback, AirPlay, timer and an MDK-only notebook/provenance register. No Google advertising SDK, test banners, purchases or analytics. Source/license links and provider disclosures are shown. Bundle ID com.radioonlinepro.player.

Build 9 candidate: requires macOS CI, signed upload and physical device testing. App Review 4.3/4.2.6 remains unresolved; restoring stations and renaming alone do not prove differentiation. See RIGHTS.md and PRIVACY.md.
